# Bible Dept and ARMA style and taste guide

Build the next project in the same family as The Bible Dept and ARMA: confident teaching, warm human presence, strong typography, restrained orange, and a clear next step. Use **The Bible Dept as the default for BibleDept products**, and ARMA as a related editorial direction for courses and campaigns.

This guide covers brand judgment, measured visual foundations, page structure, components, imagery, voice, interaction, accessibility, and application to this repository. It records the public sites as inspected on **October 18, 2026**. It is a working design reference, not a claim of an official brand manual or shared authorship.

**For one document you can view and share, open the [illustrated visual style guide PDF](BibleDept-and-ARMA-Visual-Style-Guide.pdf).** Its 19 pages bring together the palettes, type specimens, source imagery and logos, layout diagrams, component examples, app patterns, voice, and review checklist. The PDF has searchable text and section bookmarks. Font substitutes and proposed examples are labeled.

## Evidence language

**Observed** means visible in an inspected public page or its computed styles. **Extracted** means present in downloaded CSS; a utility may exist without being used. **Recommended** means a proposed rule for the next project. **Existing repository** means already implemented here, independently of the marketing sites.

Preserve these distinctions when handing the guide to another designer or coding agent. In particular, a CSS font declaration does not grant permission to redistribute a font, and a marketing pattern does not establish an app feature.

## Start a new project

1. Choose a brand direction before choosing components. Default to Bible Dept for a daily reading product.
2. Start with ink, paper, one orange, a bold sans-serif headline, and generous space.
3. Write the reader's promise and one primary next action before adding artwork.
4. Use a real teacher portrait or purposeful teaching image; keep reading surfaces quiet.
5. Adapt the page rhythm to the task. Marketing welcomes and explains; the app helps someone resume reading.
