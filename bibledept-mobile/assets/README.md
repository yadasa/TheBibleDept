# Brand asset

`bibledept-navbar-logo.avif` is the unchanged artwork used in the navbar of [thebibledept.com](https://www.thebibledept.com/), retrieved October 18, 2026 at the owner's request. [Original Webflow CDN asset](https://cdn.prod.website-files.com/674cc980f268a519ba404a37/676063236deed8f01ccc9e31_TBD%20Texture%20Logo.avif).

Expo Image renders the bundled AVIF on web/native. The original file already includes alpha transparency, which is preserved. It displays at its native 580:229 aspect ratio, without an added background, letterboxing, or padding. No substitute logo or font was generated. The existing app icons remain unchanged.

The background grain is a small deterministic vector pattern in `src/components/GrainBackground.tsx`; it does not fetch an image or run a continuous animation.
